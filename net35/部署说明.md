# HRV中间件 - .NET 3.5 部署说明

## 环境要求

- 操作系统：Windows Server 2008 及以上
- .NET Framework：3.5（Windows Server 2008 及以上通常自带）

## 部署步骤

### 1. 编译程序

使用 Visual Studio 2008 或更高版本打开 `HRVMiddleware.csproj`，选择 Release 配置进行编译。

或者使用 MSBuild 命令行编译：

```
cd net35
msbuild HRVMiddleware.csproj /p:Configuration=Release
```

编译后的文件位于 `bin\Release` 目录。

### 2. 配置程序

编辑 `App.config` 文件（或编译后的 `HRVMiddleware.exe.config`）：

```xml
<!-- HIS数据库连接字符串 -->
<connectionStrings>
  <add name="HISDatabase" 
       connectionString="Data Source=你的HIS数据库服务器;Initial Catalog=你的数据库名;User ID=用户名;Password=密码;" 
       providerName="System.Data.SqlClient"/>
</connectionStrings>

<!-- HRV系统配置 -->
<appSettings>
  <add key="HRVBaseUrl" value="http://HRV一体机IP:8080"/>
  <add key="HRVUsername" value="你的HRV用户名"/>
  <add key="HRVPassword" value="你的HRV密码"/>
  <add key="HRVAuthMode" value="password"/>
  <add key="SyncIntervalSeconds" value="60"/>  <!-- 同步间隔，单位秒 -->
  <add key="ReportSavePath" value=".\Reports"/>
  <add key="ReportFormat" value="PDF"/>
  <add key="LogFilePath" value=".\Logs\app.log"/>
</appSettings>
```

### 3. 修改HIS数据库SQL查询

在 `Services\HISDatabaseService.cs` 中，根据实际的HIS数据库表结构修改SQL查询语句：

```csharp
string sql = @"
    SELECT 
        身份证号 as caseNo,
        姓名,
        性别,
        出生日期,
        身高,
        体重,
        运动等级
    FROM 你的患者表  -- 修改这里的表名
    WHERE 身份证号 IS NOT NULL 
      AND 姓名 IS NOT NULL
    ORDER BY 创建时间 DESC";
```

### 4. 部署文件

将以下文件复制到服务器：
- `HRVMiddleware.exe`
- `HRVMiddleware.exe.config`

### 5. 运行程序

**方式1：直接运行（测试用）**
```
双击 HRVMiddleware.exe 运行
```

**方式2：使用Windows服务（推荐生产环境）**

可以使用 NSSM (Non-Sucking Service Manager) 或类似工具将程序注册为Windows服务，这样可以开机自启动。

**方式3：使用任务计划程序**

设置一个定时任务，定期运行程序（如果只需要单次同步模式）。

## 目录结构

程序运行后会自动创建以下目录：

```
HRVMiddleware/
├── HRVMiddleware.exe
├── HRVMiddleware.exe.config
├── Reports/              # 报告保存目录
│   ├── 身份证号_时间戳.pdf
│   └── 身份证号_时间戳_parameters.json
└── Logs/
    └── app.log           # 日志文件
```

## 日志查看

日志会同时输出到控制台和日志文件 `Logs\app.log`。

日志级别：
- INFO：正常操作信息
- WARNING：警告信息
- ERROR：错误信息

## 故障排查

### 1. HIS数据库连接失败
- 检查连接字符串是否正确
- 确认HIS数据库服务器可访问
- 确认用户名密码正确

### 2. HRV系统连接失败
- 检查HRV一体机IP地址是否正确
- 确认HRV系统已启动且API已开启
- 检查用户名密码是否正确

### 3. 报告保存失败
- 检查Reports目录是否有写入权限
- 确认磁盘空间充足
